A minor page fault will occur when there is no mapping to a page in place, however, the page is located in memory. The page table can be updated to correct this and is an easier fix, which is why it is a minor fault. A major page fault is much more resource-intensive to correct. A major page fault occurs when a page is references but it is not present in memory. This means the page needs to be brought in from disk memory, which is a longer and more resource-intensive process than simply accessing RAM.
